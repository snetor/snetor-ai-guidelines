Cette slide a été recalculée sur les hypothèses unitaires du chiffrage programme du 17-07 : mêmes coûts d'ETP, data steward, infra/IA et contingence pour tous les candidats. C'est le point à tenir si on challenge les chiffres : il n'y a plus qu'un seul jeu d'hypothèses dans le deck, et la réconciliation avec la slide TCO programme est exacte (+24 k€ d'intégration CRM Twenty). Deux points à assumer si la question vient. Un : Pimcore passe du milieu de tableau au plus cher, parce qu'on lui applique enfin la charge interne réelle d'un self-hosted (1 ETP dev/DevOps, comme le full custom) en plus du devis Datasolution et de la licence — sa note TCO a été ramenée de 4,0 à 2,75 en conséquence. Deux : faute d'offre chiffrée, SpecialChem est aligné sur le comparable Akeneo — d'où deux barres identiques ; c'est une hypothèse, pas une donnée, et c'est la note TCO (2,5) qui porte le risque d'un prix non contractualisé.

TCO programme · les 2 finalistes

Sur trois ans, le home-made économise 63,75 k€ — contre +0,5 ETP recruté

Périmètre programme : PIM produit + CRM interne (Twenty) · une seule équipe recrutée, un seul budget
Détail TCO 3 ans — PIM + CRM Twenty (k€)

Build (4 mois) + 3 × run annuel, ventilés par poste. L'équipe recrutée (dev/DevOps + data steward) et l'infra servent PIM et CRM : le CRM Twenty n'ajoute que son intégration, pas un run dédié. Capacité existante mutualisée exclue. Source : note §8.

Akeneo PIM + CRM Twenty

86 k€ build + 175,75 k€/an de run → 613,25 k€ / 3 ans. Run : 0,5 ETP dev/DevOps + 0,4 ETP data steward + licence Akeneo.

PIM home-made + CRM Twenty

44 k€ build + 168,5 k€/an de run → 549,5 k€ / 3 ans. Run : 1 ETP dev/DevOps + 0,4 ETP data steward.

Le prix n'arbitre pas seul : Akeneo achète une maturité produit et du support ; le home-made internalise davantage de capacité (1,4 ETP recrutés vs 0,9). L'écart financier est de 63,75 k€ sur trois ans.
TCO issu du fichier de chiffrage programme : build de quatre mois, puis trois années de run. Akeneo + Twenty : 86 + 3 × 175,75 = 613,25 k€. Home-made + Twenty : 44 + 3 × 168,5 = 549,5 k€. Les ETP déjà présents sont mutualisés et non revalorisés ; les coûts additionnels comprennent les recrutements.
Source : note de décision PIM §8 (TCO + staffing)
Décision COMEX

Deux approches en tête, au coude-à-coude : acheter ou construire ?

Décision sur le programme complet : PIM produit + CRM interne (Twenty) · une seule équipe, un seul budget

Acheter — Akeneo (87)

Importer la maturité : couverture native, pérennisation, support éditeur, certitude de delivery. Programme PIM + Twenty : 86 k€ build, puis 175,75 k€/an.

Condition à lever : figer le périmètre des 2 custom apps et le chiffrage intégration.

Construire — full custom (86)

Internaliser la compétence : meilleure adoption (maquette validée), fondation data, autonomie. Programme PIM + Twenty : 44 k€ build, puis 168,5 k€/an ; 1,4 ETP recrutés en run.

Condition à lever : capacité interne non saturée, plan anti-homme-clé, fonctions de base bornées (DAM, versioning, « dernier doc valide »).

Deux décisions pour le COMEX : (1) acheter (Akeneo) ou construire (home-made) — au-delà du score, un choix stratégique ; (2) valider le staffing du programme : 0,9 ETP recruté avec Akeneo ou 1,4 ETP avec le home-made. Un benchmark final sur dataset confirme.
Deux approches se détachent, quasi à égalité (Akeneo 87, full custom 86) : le choix est stratégique, pas arithmétique — importer la maturité ou internaliser la compétence. Les deux passent par un benchmark final sur dataset Snetor. Conditions full custom : capacité interne non saturée, plan anti-homme-clé, MVP 1-2 sem., fonctions de base bornées. Akeneo : figer périmètre 2 custom apps + chiffrage. 2ᵉ décision COMEX : staffing 1 personne (0,5 ETP, risque homme-clé) vs 2 personnes (0,25 + 0,25). SpecialChem est un challenger à confirmer par une démonstration du workflow de validation, de l'extraction IA et par une offre chiffrée. inriver = alternative SaaS premium si route buy.
Source : note de décision PIM §9 (recommandation) — décision stratégique, pas arithmétique

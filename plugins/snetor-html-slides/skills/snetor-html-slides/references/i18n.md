# i18n — UI Strings Dictionary

Detection rules and per-language string table for Snetor HTML slides.

---

## Detection rules

Apply in this order:

1. If user explicitly says "in French / en français" → FR
2. If user explicitly says "in English / en anglais" → EN
3. If user explicitly says "in Spanish / en español / en espagnol" → ES
4. Otherwise: detect from the language of the user's request itself
5. If detection fails → default to FR (Snetor's primary language)
6. For any other language: generate slide content in that language, but use the EN dictionary as fallback for UI chrome strings

## HTML lang attribute

Always set `<html lang="{{detected}}">` to the ISO code:
- French → `fr`
- English → `en`
- Spanish → `es`
- Other → use the standard ISO 639-1 code (de, it, pt, etc.)

---

## Headlines and content

Slide content (h1, h2, body text, statements, fact-card descriptions, eyebrow labels specific to a topic) is generated by Claude in the detected language. Only the UI chrome strings (default eyebrows like "Sources", check-card status labels, nav aria-labels, footer "Sources") come from this dictionary.

Eyebrow labels that are content-specific (e.g. "Cloud market 2025", "Decision moment") are written by Claude in the deck language and are NOT looked up here.

---

## Date formatting

Use the conventions of the deck language:
- FR : `6 mai 2026`
- EN : `May 6, 2026`
- ES : `6 de mayo de 2026`
